# VOX — A Digital Learning Object for Oral Participation

[**Try VOX — Live Demo**](https://vox-ten-beta.vercel.app/)

VOX is a web-based learning object designed to encourage, scaffold and strengthen students' oral participation through guided thinking, spoken practice and AI-supported feedback.

Developed at the intersection of educational design and software development, VOX provides students with a structured space to think, articulate ideas, record their responses, receive feedback and reformulate their thinking.

## The Educational Problem

Oral participation is an essential part of learning, yet many secondary school students struggle to engage in meaningful oral exchanges in the classroom.

VOX addresses this challenge by providing a digital environment where students can prepare their ideas, develop their reasoning and practise expressing themselves orally before, and as part of, classroom interaction.

Rather than focusing solely on producing an answer, VOX encourages students to clarify, develop, connect and challenge their thinking.

## Learning Experience

VOX structures oral practice into three stages:

### 1. Think

Students engage with a challenge and use thinking activators to explore, organise and expand their ideas before speaking.

### 2. Build

Students articulate their ideas, record their oral response and receive AI-supported feedback aimed at helping them strengthen their reasoning and expression.

### 3. Ready to Speak

Students can revisit their initial response, record a second attempt and reflect on how their ideas have developed.

The experience encourages revision, elaboration and the development of more meaningful oral contributions.

## Key Features

- **Challenge-based learning:** Activities designed around interpretation, reasoning, argumentation, connections and perspective-taking.
- **Thinking activators:** Clarify, Develop, Connect and Challenge, helping students move beyond short or superficial responses.
- **Speaking Studio:** A dedicated workspace for recording, listening to and revisiting spoken responses.
- **AI-supported feedback:** Feedback designed to prompt students to expand, clarify, strengthen and reconsider their ideas.
- **Multiple recording attempts:** Students can revisit and reformulate their oral contributions.
- **Challenge library:** A collection of learning activities organised by subject or learning context.
- **Student Space:** Access to challenges, assigned activities when available, and a space to explore evidence of thinking development.
- **Teacher Space:** A teacher-oriented environment for organising courses and activities.

## Learning Contexts

VOX is designed to support oral participation across different learning contexts, including:

- Literature and Language
- English
- Global Perspectives

Challenges can be built around literary texts, controversial issues, questions for inquiry, classroom debates and other curricular content.

## AI Integration

VOX integrates AI to provide formative feedback on students' written reflections and oral practice process.

The feedback aims to encourage students to:

- Clarify ideas and reasoning.
- Develop arguments and explanations.
- Make connections.
- Explore alternative perspectives.
- Strengthen and reformulate oral contributions.

AI is integrated as a pedagogical support rather than as a replacement for students' thinking or teachers' guidance.

## Technology Stack

- **React** — Front-end development and component-based interface.
- **Vite** — Development environment and build tooling.
- **JavaScript** — Application logic.
- **CSS** — Interface styling and responsive design.
- **Gemini API** — AI-supported reflection and feedback.
- **MediaRecorder API** — Recording and playback of oral responses.
- **Vercel** — Deployment and hosting.

## Project Development

The development process combines:

- Educational problem analysis.
- Learning experience and interaction design.
- Front-end development.
- AI integration.
- Iterative interface design and functional development.

## Current Scope

VOX currently provides a functional web-based learning experience for guided thinking and oral practice.

Some features, including data persistence, teacher-student management, progress tracking across sessions and scalable course management, are part of the project's ongoing development.

## Run Locally

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/laclaupau/VOX.git
cd VOX
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build the application:

```bash
npm run build
```

### Environment Variables

AI-powered features require the appropriate API configuration.

Environment variables should be configured locally and in the deployment platform. API keys should never be committed to the repository.
